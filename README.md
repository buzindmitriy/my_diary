# MyDiary — Личный дневник на Django 📖

> Простое веб-приложение для ведения личного дневника, написанное на **Django 5**, с поддержкой:
- Markdown
- Изображений к записям
- Групп пользователей: *Пользователь*, *Редактор*, *Администратор*
- Разграничение прав через `perms`
- Регистрация с email-подтверждением
- Кэширование через Redis
- Поддержка Docker + PostgreSQL

---

## ✨ Функционал

- Вести записи с поддержкой Markdown
- Добавлять изображения к записям
- Использовать теги и фильтры
- Поиск по заголовкам, содержимому или тегам
- Только автор может редактировать/удалять свою запись
- Суперпользователь имеет полный доступ
- Отправка приветственного письма при регистрации
- Красивые шаблоны с Bootstrap 5

## 🧰 Установка

### 1. Клонирование репозитория

Склонируйте репозиторий с GitHub:

```
git clone https://github.com/buzindmitriy/my_diary
cd my_diary
```
### 2. Запустите сборку

```
docker-compose exec web python manage.py migrate
```

### 3. Выполните миграции 

```
docker-compose exec web python manage.py migrate
```

### 4. Создайте суперпользователя 

```
docker-compose exec web python manage.py createsuperuser
```

### 5. Откройте браузер

```
http://localhost:8000/
```
